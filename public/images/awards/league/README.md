# Liigakauden pääpalkinnot

Vie tähän kansioon läpinäkyvät PNG-kuvat täsmälleen näillä nimillä:

- `crystal.png` — kristalli
- `pennant.png` — viiri
- `sculpture.png` — veistos

Samat kuvat näkyvät liigan pääsivulla, tapahtumien etusivun liigakortissa ja voittajan henkilökohtaisessa palkintovitriinissä. Jos kuvaa ei vielä ole, sovellus näyttää väliaikaisen kuvakkeen.

Suositus: rajaa läpinäkyvät marginaalit tiukasti itse palkintoon, säilytä mittasuhteet ja käytä riittävää resoluutiota (esim. 1024 × 1024 px).
